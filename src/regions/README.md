# Metropolitan boundaries

These GeoJSON files are snapshots of OpenStreetMap relations, obtained through
Nominatim's lookup API on 2026-09-21 with `polygon_threshold=0.0001`:

- `greater-london.json`: [relation 175342](https://www.openstreetmap.org/relation/175342)
- `barcelona-metropolitan.json`: [relation 18205773](https://www.openstreetmap.org/relation/18205773)
- `new-york.json`: [relation 175905](https://www.openstreetmap.org/relation/175905)

Map data © OpenStreetMap contributors, available under the Open Database License.
The Barcelona relation represents the Àrea Metropolitana de Barcelona, which
includes El Prat de Llobregat. Keep the region name, identifier, and geometry
together when updating either snapshot.
